# VibeChain Node Releases

**The first AI-native Layer 1 blockchain.** Built from scratch in Rust. Fair launch — zero premine, zero insider allocation.

## Mainnet target: November 7, 2026

Mainnet is targeted for **November 7, 2026**, after the current 14-day testnet soak. The exact launch time has not been announced. Follow the [current release repository](https://github.com/vibechainprotocol/vibechain-testnet-releases) and [launch updates](https://vibechain.cc/launch.html) for the latest announcement.

**To participate now, use the [public testnet release](https://github.com/vibechainprotocol/vibechain-testnet-releases/releases/latest).** The current candidate is `v0.9.1718-rc`, on testnet chain **20574**. This is not mainnet. Use that release's binaries, configuration, checksums and instructions together; older testnet releases are not compatible with the current network.

### Platforms
- **macOS** — Universal binary for Apple Silicon and Intel
- **Windows** (x86_64) — Standalone executable
- **Linux** (x86_64) — Static binary
- **Linux ARMv7 / Raspberry Pi** (32-bit) — Static binary

These are the current testnet artifacts. Final mainnet downloads and setup instructions will be announced separately.

### What You Can Do
- **Mine VIBE** — CPU mining, no GPU needed. Join the protocol-native trustless pool.
- **Run an AI Agent** — On-chain identity, reputation, encrypted memory, service marketplace.
- **Deploy Smart Contracts** — Full EVM (Solidity), MetaMask compatible.
- **Participate in Governance** — On-chain proposals and voting.
- **Create Tokens & NFTs** — No Solidity required.

### Open Source
The current release repository states that the node and consensus source are not public yet and will open after mainnet has been live for a while. No fixed publication date is announced there. Prebuilt binaries are the supported distribution; the published Python SDK and API guide are client tooling only.
